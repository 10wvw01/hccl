关键点
• 切分：每个 peer 的分片由 CalcDataSplitByPortGroupZAxisDetour 按 ratio 0.5 切成连续两段，level0 段 [0, L0)、level1 段 [L0, total)。
• write 模式：root 主动写远端，各通道写不同 offset → 对端 buffer 原位连续拼接，无需 PostCopy 重组。
• 确定性：root 与 non-root 用相同输入算切分，per-channel 分片一致。
• 尾块：tailSize 同样跨通道切分；scatter 是写远端、无同 buffer 自拷贝，故 [400,404) 自交叠类不适用，风险在切分确定性/count（须 count%rankSize==1 用例覆盖）。
• 图模式：enableRemoteMemAccess_ 时所有通道一致直写远端 OUTPUT（待核实 level1 通道是否填 remoteOutputGraphMode）。
