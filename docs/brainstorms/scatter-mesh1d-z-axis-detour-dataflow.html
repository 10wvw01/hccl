关键点
• 切分：每 peer 分片由 CalcDataSplitByPortGroupZAxisDetour 两级切——level0/level1 = 0.5/0.5；clos 50% 再按端口号 2:6 分给 port2/port6。
• 比例：mesh 50% / port2 = 50%×2/8 = 12.5% / port6 = 50%×6/8 = 37.5%，合计 100%。
• 连续 offset：mesh [0, 0.5T) → port2 [0.5T, 0.625T) → port6 [0.625T, T)，write 各链路写不同 offset → 原位拼接，无需 PostCopy 重组。
• write 模式：root 主动写远端；root 与 non-root 切分确定性一致。
• 尾块：tailSize 同样跨三链路切分；scatter 写远端无同 buffer 自拷贝，[400,404) 自交叠类不适用，风险在切分确定性/count（须 count%rankSize==1 用例覆盖）。
